# 磁标脉冲串解码器

纯前端（TypeScript + React + Vite + SVG）磁标读头脉冲串分析工具。读头速度漂移会让同一段脉冲在不同候选时钟下出现不同解释，本工具**枚举全部整数时钟 τ = 80..120μs** 逐一尝试成帧，并判明解码出的数字串是否唯一：

- **decoded** —— 恰好一种数字串（可由多个 τ 解出），展示 τ 范围并按**最小 τ** 绘制间隔分类与成位图；
- **ambiguous** —— 存在多种不同数字串，按数字串字典序列出每种串对应的全部 τ；
- **unreadable** —— 没有任何 τ 能解出合法帧。

所有计算只发生在浏览器本地，无后端、无网络请求。

## 输入格式

一个 **JSON 整数数组**，元素为相邻脉冲边沿之间的间隔时长（微秒）：

- 元素个数：**6..200**；
- 每个元素：**20..150 之间的整数**（不接受小数、布尔、null、字符串）；
- 须为合法 JSON，例如：

```json
[100, 50, 50, 98, 103, 49, 51, 100, 100, 100, 100, 100, 100, 100, 100]
```

输入不合法时**整份拒绝**：所有错误按位置稳定汇总（根错误 `$` 在最前，元素错误以 `$[i]` 按索引升序），同时清除上一次的解码结果，不会显示陈旧答案。

## 解码规则

对每个整数 τ ∈ [80, 120]：

1. **间隔分类**（互斥）
   - 长型：`|d − τ| ≤ 6`；
   - 短型：`|2d − τ| ≤ 6`；
   - 同一间隔同时满足两者 → 淘汰该 τ；两者都不满足 → 淘汰该 τ。
2. **成位**
   - 一个长型间隔成位 **0**；
   - **相邻两个**短型间隔成位 **1**；
   - 落单的短型（孤立短型）→ 淘汰该 τ。
3. **码组**：位流每 5 位一组。前 4 位**低位在前**组成码值（bit0 是最低位）；第 5 位为奇校验位，必须使本组中 1 的总数为奇数，否则淘汰该 τ。
4. **帧结构**（帧外不得有任何多余位）：
   `起始码 11` + `1..12 个载荷码` + `结束码 15` + `LRC`
   - 起始码不是 11、结束码不是 15 → 淘汰；
   - 载荷码数量不在 1..12，或任一载荷码值超出 0..9 → 淘汰；
   - LRC 低 4 位必须等于此前所有码值（起始、载荷、结束）逐位异或，否则淘汰。

通过全部检查的 τ 为**有效 τ**，其载荷码 0..9 依次拼成数字串（保留前导零，如 `0042`）。最后按数字串归并：0 组为 unreadable，1 组为 decoded，多组为 ambiguous（字典序排列）。

### 关于 ambiguous 的数学说明

在本规格的常数下，长型条件等价于 τ ∈ [d−6, d+6]、短型条件等价于 τ ∈ [2d−6, 2d+6]。整数 d 下两窗口在 τ∈[80,120] 内互不相交，因此单个间隔的长/短归类不会随 τ 翻转——真实脉冲数据通常只会得到「同串多 τ」或「无解」。ambiguous 分支仍被完整实现并由测试（构造数据的组件测试与纯函数单测）覆盖，以严格满足规格并防止回归。

## 本地运行

需要 Node.js 20+。

```bash
npm install
npm run dev        # 开发服务器（默认 http://localhost:5173）
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview    # 预览构建产物
```

## 验收测试

```bash
npm run test       # Vitest 单元 / 组件测试（27 个用例）
npm run test:e2e   # Playwright 端到端（自动拉起 Vite dev server，共 6 个用例）
npm run typecheck  # 仅做 TypeScript 类型检查
```

Playwright 首次运行需要浏览器二进制：`npx playwright install chromium`（CI/Linux 若缺系统库可用 `npx playwright install --with-deps chromium`，需 root）。

## Docker

```bash
# Web 服务：宿主端口由 WEB_PORT 覆盖（默认 8080），容器内 nginx 固定监听 80
WEB_PORT=9090 docker compose up --build web
# 打开 http://localhost:9090

# 一次性验收服务：类型检查 + Vitest + Playwright，全过则退出码 0
docker compose up --build verify
docker compose rm -f verify   # 验收容器不会自动重启
```

- `web`：多阶段构建，Vite 产物由 nginx 静态托管，纯前端、无运行时计算服务；
- `verify`：基于 Playwright 官方镜像（已预装 Chromium 与系统库），跑完即退出。

## 目录结构

```
src/
  lib/decoder.ts        纯函数核心：校验、分类、成位、成帧、LRC、τ 枚举与归并
  lib/encoder.ts        演示/测试用互逆编码器（可注入漂移与抖动）
  components/           ResultView（结果三态）、PulseDiagram（SVG 时序图）
  App.tsx               输入、错误稳定汇总、整份拒绝
e2e/app.spec.ts         Playwright 端到端验收
```
